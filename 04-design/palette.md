# Palette Benoît Raffard — Hypnothérapeute Bordeaux

Dérivée du logo officiel : pont de Bordeaux, soleils orange, Garonne bleue.

## Variables CSS

| Variable | Hex | Usage |
|---|---|---|
| `--color-accent` | `#5B7FA8` | Bleu Garonne — boutons, liens, hover, badges |
| `--color-accent-light` | `#87A3C2` | Bleu clair — états secondaires |
| `--color-accent-dark` | `#3F5E80` | Bleu profond — hover boutons |
| `--color-accent-bg` | `#E5EDF5` | Fond bleu très clair — arrière-plans |
| `--color-gold` | `#E8884E` | Orange terracotta — étoiles, accents chauds |
| `--color-text` | `#3A2E26` | Brun foncé — texte principal |
| `--color-text-soft` | `#6E5848` | Brun chocolat — sous-titres |
| `--color-text-muted` | `#8A847A` | Gris taupe — meta, labels |
| `--color-bg` | `#FDFBF7` | Crème — fond général |
| `--color-bg-warm` | `#F5EDE2` | Beige chaud — sections alternées |
| `--color-border` | `#E0D7C7` | Beige — bordures |
| `--color-white` | `#FFFFFF` | Blanc — cards, surfaces |

## Typographies

- **Display** : Cormorant Garamond (titres, serif italique)
- **Body** : DM Sans (corps de texte, sans-serif)

## Règles d'usage

- **Bleu** = tout ce qui est interactif (CTA, liens, hover). Évoque le calme et la sérénité.
- **Orange** = accents émotionnels uniquement (étoiles témoignages, citations, highlights). Jamais sur les CTA principaux.
- **Brun** = textes. Plus chaleureux qu'un noir pur, cohérent avec le logo.
